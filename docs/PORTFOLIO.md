Scanned Documents to Validated Data & Search with Page Citations

**Description**

Built a working document intelligence pipeline that converts scanned invoices and contracts into
validated structured data, routes uncertain fields for human review, and answers questions with
document-and-page evidence. Python/FastAPI, React, local Tesseract OCR, Ollama and Weaviate power a
private local workflow with content-based deduplication, durable processing checkpoints and
highlighted source verification. Independent reference implementation using synthetic data only.
