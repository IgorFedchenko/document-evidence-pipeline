Every file in `documents/` is generated by `scripts/generate_fixtures.py`. Names, amounts and dates
are invented; these are not real invoices or agreements. PDFs are deliberately image-only and
require OCR. The PNG exercises scan upload. `needs-review.pdf` omits required fields on purpose.

`expected.json` is the human-authored gold set. `responses/` contains manually authored schema-valid
model responses for deterministic tests, not a claim about live model accuracy. Fixtures are MIT licensed.
